# 🌌 Finance Dashboard — Glow UI Edition

A clean, modern and fully interactive Finance Dashboard built using HTML, CSS and JavaScript with glowing purple aesthetics, real-time charts and complete transaction management.

# ✨ Features
🎨 Beautiful Glowing UI
Purple nebula background with star shine
Glassmorphism cards
Floating neon glow effects
Centered animated Finance Dashboard title

# 📊 Dynamic Real-Time Charts
Line Chart → Month-wise trend
Pie Chart → Category-wise spending
Charts update whenever a transaction is added, edited, deleted

# 🧾 Transaction Management
Add new transactions
Edit existing transactions (full working)
Delete transactions
Modal always opens blank
Clean “No Data” placeholder when empty

# 🧑‍💼 Role-Based UI (Frontend)
Admin → Full access (Add, Edit, Delete)
Viewer → Read-only
Role switch via dropdown

# 🔍 Insights Engine
Highest spending category
Monthly comparison
Total transactions

# 🗂️ Project Structure
Finance-Dashboard/


├── index.html      → All UI structure  
├── style.css       → Glow, shine, animations, layout  
├── script.js       → Logic, charts, role, modal, insights  


# 🚀 Getting Started
1. Clone the repository
2. Open the project
3. Run the dashboard
No build step required.
